
# 🚀 Smart API Assistant

Assistente desenvolvido em Python para consultar e compreender códigos de status HTTP utilizados em integrações de APIs.

## 📌 Sobre o projeto

O Smart API Assistant é um projeto de aprendizado criado para facilitar a compreensão de erros HTTP, apresentando seus nomes e descrições.

A ideia surgiu a partir da minha experiência profissional com suporte técnico a clientes que utilizam APIs no setor financeiro.

## ⚙️ Funcionalidades

- Consulta de códigos HTTP
- Exibição de nomes e descrições dos erros
- Identificação de códigos não cadastrados
- Consultas repetidas pelo terminal
- Testes automatizados com unittest

## 🛠️ Tecnologias

- Python
- Biblioteca unittest
- Git e GitHub
- Visual Studio Code

## ▶️ Como executar

É necessário ter o Python instalado.

No terminal, execute:

```bash
python main.py
```

Digite um código HTTP para consultar sua descrição.

Para encerrar, digite `sair`.

## 🧪 Como executar os testes

```bash
python -m unittest -v
```
